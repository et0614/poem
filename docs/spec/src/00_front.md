## 規定の表現 {.unnumbered}

本文には「規定」と「解説」がある。規定は、この仕様に適合するために守るべき事項であり、次の表現で書く。解説は、規定の理由・背景・例であり、「解説:」で始めるか、規定の表現を使わずに書く。

| 表現 | 意味 |
|---|---|
| しなければならない | 必須。守らない実装はこの仕様に適合しない |
| してはならない | 禁止。行う実装はこの仕様に適合しない |
| することを推奨する | 推奨。正当な理由があれば従わなくてよい |
| してもよい | 任意。行っても行わなくても適合する |

数値などの表記は次のとおりとする。

- 0x で始まる値は 16 進数とする (例: 0x0300)。
- バイト数は B と書く (例: 32 B)。
- 範囲は「〜」で表し、両端を含む (例: 0x08〜0x77)。

## 用語と略語 {.unnumbered}

| 用語 | 定義 |
|---|---|
| OSL | I²C でつながるセンサ機器のための、汎用の共通レジスタの仕様 (OSL 共通レジスタ)。第 2 章で定める。特定の製品に依存しない |
| PoEM | OSL を使った計測システムの実装の一つ。この文書の第 3 章以降が対象とする |
| 子機 | センサを持ち、I²C で計測値を提供する機器。OSL を実装する |
| 上位機器 | 子機を I²C で読み書きする機器の総称。PoEM では PoEM Pod と PoEM Link |
| PoEM Pod | PoE で給電され、I²C で子機を読み、MQTT で計測値を送る機器 (親機) |
| ノード | PoEM Pod が子機ごとに持つ管理用の記録。子機そのものではない |
| PoEM Server | MQTT ブローカーを兼ね、PoEM Pod から受けた計測値を BACnet で公開するソフトウェア |
| PoEM Link | スマートフォンや PC と子機を USB で中継する機器 |
| PoEM Link 用アプリ | PoEM Link を使って子機を読み書きする、スマートフォン・PC 用のアプリ |
| PoEM Tap | Qwiic の配線を分岐する基板 |
| BMS | 建物の中央監視・管理システム (Building Management System) |
| Qwiic | JST SH 4 ピンのコネクタを使う I²C の配線の規格 |
| UID | 子機の個体 ID。16 B の値で、子機の個体を区別する唯一の正式な識別子 |
| 表示用 ID | UID から計算する短い値。人が見分けるためのもので、識別子としては使わない |
| チャネル | 子機が提供する計測値の 1 系列 (例: 温度、湿度) |
| Reliability | BACnet で値の信頼性を表す列挙値。子機の状態コードにも使う |
| TSC コード | 建築設備分野で定義されている名前付けの規則による、点の名前 |
| BACnet | 建物の設備の通信の規格 (ANSI/ASHRAE 135、ISO 16484-5) |
| MQTT | 発行と購読による軽量な通信の規格 |
