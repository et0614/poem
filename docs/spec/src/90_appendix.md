# 付録 E 場面ごとの動作 {.unnumbered}

| 場面 | PoEM Pod | PoEM Server・BMS |
|---|---|---|
| 新しい子機をつなぐ | 10 秒以内に増分の走査で見つけ、config を送る | オブジェクトを作る |
| 子機を抜く | 状態 12 の data を毎秒送る。再プローブを続ける | Reliability 12、値は据え置き |
| 同じ子機を挿し直す | 再プローブで同じ UID を確かめ、POLL を再開する。config は送らない | 正常に戻る |
| 同じアドレスに別の個体 (同じ機種) を挿す | 再プローブで UID の変化を検知し、config を送ってから data を送る | オブジェクトを作り直す。番号は変わらない |
| 同じアドレスに別の機種を挿す | 同上 | 同上 (チャネルの構成が変わる) |
| 同じアドレスに OSL 以外の機器を挿す | OSL の子機ではないと記録し、書き込まない | 状態 12 のまま |
| 子機のアドレスを変える (PoEM Pod の設定のモード) | 再起動の後の全体の走査で、新しいアドレスで見つける | 同じ UID の移動として、古いアドレスのオブジェクトを消し、新しいアドレスに作る |
| 子機を別の PoEM Pod に移す | 移した先の PoEM Pod が見つける | 移した先にオブジェクトを作る。古いオブジェクトは状態 12 のまま残る |
| PoEM Pod の停止、LAN の切断 | — | 値は据え置かれ、base + 0 の日時が止まる (受信の途絶の判定は未決) |
| PoEM Server の再起動 | 再接続の後の全体の走査で config を送り直す | オブジェクトを作り直す |
| config が失われる | — | data を無視する (次の全体の走査まで) |
| 途中から接続した MQTT クライアント | — | 次の config まで、チャネルの名前や UID が分からない |
| 子機の名前を変える | 次の config で新しい名前を送る | base + 2 の値が変わる。Object_Name は変わらない |
| 子機の再起動 | uptime_s の巻き戻りを検知し、識別区画を確かめる。node/diag を送る | 稼働時間が 0 からになる |

この表のうち、交換・再起動の検知 (再プローブ、uptime_s の巻き戻り) は、この文書で定めた動きであり、現在の PoEM Pod のファームウェアには未実装である (付録 F)。

| 項目 | 決定 | 理由 |
|---|---|---|
| オブジェクトの番号を種類ごとに 0 から振り直す案 | 採らない | 一般の BMS は番号だけで点を区別するので、1 台の Device の中で番号を重ねない (1.3 節の原則 3) |

| プルアップの置き場所 | 子機には持たせず、上位機器と PoEM Tap に置き、配線に合わせて入切する | 子機ごとに持たせると、台数に比例して強くなりすぎる |
| 補正係数の置き場所 | ユーザー領域 (機種ごと)。OSL の共通の区画には入れない | 補正の形が機種で違う (風速センサは非線形) |
| 校正の履歴 | 子機には持たせず、PC の側に UID ごとの記録として残す | 子機の不揮発メモリと作り込みの負担を増やさない |
| 校正の道具 | PC の道具で行う。PoEM Link 用アプリでは行わない | 補正係数はユーザー領域にあり、OSL と PoEM の仕様の外にある。PoEM Link 用アプリは仕様に定めた機能だけを使う |

# 付録 H (参考) PoEM の子機のユーザー領域 {.unnumbered}

この付録は、PoEM の子機の内部の定義を参考として示す。OSL の規定ではなく、機種のファームウェアの更新で変わることがある。

## H.1 温湿度・絶対圧・差圧センサ {.unnumbered}

| 番地 | 温湿度 (0x0101) | 絶対圧 (0x0301) | 差圧 (0x0302、0x0303) | 型 | 既定値 |
|---|---|---|---|---|---|
| 0x1000 | 温度の a | 圧力の a | 差圧の a | float32 | 1.0 |
| 0x1004 | 温度の b [°C] | 圧力の b [Pa] | 差圧の b [Pa] | float32 | 0.0 |
| 0x1008 | 湿度の a | 温度の a | 温度の a | float32 | 1.0 |
| 0x100C | 湿度の b [%RH] | 温度の b [°C] | 温度の b [°C] | float32 | 0.0 |

差圧センサのゼロ点の校正は、差圧の b を書き換えて行う。多点温度センサ (0x0102) は、ユーザー領域を持たない。

| 0x1001 | filter_n | uint8 | 6 | 指数平滑の係数 (0〜20) |
| 0x1002 | (詰め物) | — | — | float の位置をそろえる |
| 0x1004 | E0 | float32 | 0.462 | 風速の換算式の係数 |
| 0x1008 | m1 | float32 | 0.970 | 同上 |
| 0x100C | lnC1 | float32 | 0.183 | 同上 |
| 0x1010 | m2 | float32 | 1.584 | 同上 |
| 0x1014 | lnC2 | float32 | 0.865 | 同上 |
| 0x1018 | m3 | float32 | 0.410 | 同上 |
| 0x101C | lnC3 | float32 | 0 | 同上 |
