# 付録 A レジスタ一覧 {.unnumbered}

> 執筆予定: 番地・長さ・読み書き・CRC の有無・必須か任意か、の一覧表。

# 付録 B コードの一覧 {.unnumbered}

> 執筆予定: 機種 ID (vendor_id、model_id)、単位コード (PoEM で使う BACnet Engineering Units)、状態コード (Reliability)、起動要因。

# 付録 C BACnet オブジェクト一覧の例 {.unnumbered}

> 執筆予定: Pod 2 台、子機数台の構成で、番号と Object_Name を具体的に並べた例。

# 付録 D 電文の例 {.unnumbered}

> 執筆予定: MQTT の各電文、PoEM Link の SysEx のやり取りの例。

# 付録 E 場面ごとの動作 {.unnumbered}

> 執筆予定: センサの抜き差し、同じアドレスでの交換、別機種への交換、OSL 以外の機器、アドレスの変更、Pod の移設、Pod の停止、config の喪失、途中から接続した MQTT クライアント、撤去、名前の変更。それぞれの子機・Pod・サーバ・BMS での見え方。元資料: OSL v2 通信の整理 (シナリオ)。

# 付録 F 未決事項 {.unnumbered}

| # | 項目 | 内容 | 関係する節 |
|---|---|---|---|
| 1 | BACnet の項目の配置 | 種類ごとに 0 から振り直す案 (案 B) は、BMS が番号だけで区別する前提と合わない。番号を重ねない配置で見直す | オブジェクトの番号の規則 |
| 2 | Object_Name の形式 | 表示用 ID・利用者の名前・TSC コードの入れ方、長さと文字の制約 | オブジェクトの名前の規則 |
| 3 | TSC コードの管理 | 登録・編集の方法、保存先、場所に付けるか個体に付けるか | TSC コードの管理 |
| 4 | 交換の検知 | 再プローブと uptime の巻き戻りによる検知の実装 | 子機の管理 |
| 5 | config の喪失 | retain、定期的な再送、data の短い ID | 配送の約束 |
| 6 | 受信途絶の判定 | サーバで一定時間受信が無ければ状態 12 にする | 状態の反映 |
| 7 | 撤去したセンサ | 子機の一覧の電文と、サーバでの削除 | 構成の変化への追従 |
| 8 | 校正 | 履歴の形式、ユーザ領域のレイアウトの版と移行、校正に使う道具 | ユーザ領域と補正係数、校正の手順 |
| 9 | MIDI のメーカー ID | 一般に配布する前に正式な ID を取得する | USB-MIDI の通信仕様 |

# 付録 G 参考文献 {.unnumbered}

> 執筆予定: BACnet (ANSI/ASHRAE 135、ISO 16484-5)、TSC の規定、I²C・Qwiic、USB-MIDI 1.0、各センサのデータシート。
