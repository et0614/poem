# 運用

この章は、PoEM を設置し、保守するときの手順を定める。

## 設置と立ち上げ

### 計画

設置の前に、次の事項を決め、一覧 (点の表) にまとめることを推奨する。

| 事項 | 決め方 |
|---|---|
| PoEM Server | BMS の側の IP アドレスと Device 番号。複数置く場合は IP アドレスを分ける (5.1.4 項) |
| PoEM Pod | 設置する場所、IP アドレス、名前、PoEM Server での番号 |
| 子機 | 設置する場所、つなぐ PoEM Pod、I²C アドレス、名前、TSC コード |

- 同じ PoEM Pod につなぐ子機の I²C アドレスは、重ならないように割り当てなければならない。PoEM Pod が違えば、同じアドレスを使ってよい。
- 子機の名前は、設置した場所が分かるように付けることを推奨する (例: 3F 第 2 会議室 天井 吹出口付近)。

### 配線とプルアップ

- 1 系統の I²C のプルアップは、PoEM Pod と PoEM Tap のプルアップの組み合わせで決まる。配線の長さと子機の台数に応じて、PoEM Tap のプルアップを入切しなければならない。
- 延長ケーブルを継ぎ足して信号の立ち上がりがなまる場合は、途中の PoEM Tap のプルアップを入れる。
- 入れたプルアップの合成抵抗が、およそ 1 kΩ を下回ってはならない (2.1.1 項)。

### 子機の準備

子機は、PoEM Pod につなぐ前に、PoEM Link 用アプリ (または PC の道具) で準備することを推奨する。

1. 子機を 1 台ずつ PoEM Link につなぐ (工場出荷時のアドレスはすべて 0x10 なので、同時につなぐと衝突する)。
2. 計測値が表示され、状態が正常になることを確かめる。
3. I²C アドレスを、計画した値に変える。
4. 名前を付ける。
5. 子機の本体に、名前とアドレスを書いたラベルを貼ることを推奨する。

### PoEM Pod の設定

1. Reset スイッチを押したまま PoEM Pod を起動し、設定のモードに入る。
2. Web の画面で、ネットワーク、ブローカー (PoEM Server) の IP アドレス、PoEM Pod の名前を設定する。
3. 子機をつなぎ、アドレスと名前を確かめる (必要ならこの画面でも変えられる)。
4. 再起動して、計測のモードで動かす。

### PoEM Server の設定と起動

1. setting.ini に、MQTT と BACnet の IP アドレス、Device 番号を書く (5.1.3 項)。
2. PoEM Server を起動する。PoEM Pod が接続すると、子機のオブジェクトが作られる。
3. PoEM Pod の番号が計画どおりでなければ、PodMap.json を書き換えて再起動する。

### BMS への登録

1. BMS から Who-Is を送り、PoEM Server の Device を見つける。
2. オブジェクトの一覧を読み、点の表と照らし合わせる。オブジェクトの番号の規則は 5.3 節、名前の規則は 5.4 節に示す。
3. BMS には、チャネルの値のオブジェクト (base + 10 以降) を点として登録する。必要に応じて、状態のビット (base + 3) と、最後に受け取った日時 (base + 0) も登録する。
4. 点の値の異常は、Reliability と STATUS_FLAGS の FAULT で判断する。

## 保守

### 子機の交換

- 同じ機種の子機に交換する場合は、新しい子機に、古い子機と同じ I²C アドレスと名前を設定してから、同じ PoEM Pod の同じ系統につなぐ。BACnet のオブジェクトの番号は変わらない。
- PoEM Pod は、交換を検知して新しい子機の config を送る (3.3.3 項)。PoEM Server は、UID の変化を受けて子機のオブジェクトを作り直す。
- 校正の係数は子機についているので、交換した子機の校正の状態を確かめなければならない。

### 子機の校正

1. 子機を PoEM Pod から外し、PC の道具 (USB と I²C の変換器) につなぐ。
2. 現在の係数を読み、新しい係数を書き、読み返して確かめる (6.4 節)。校正の記録を PC の側に残す。
3. 子機を PoEM Pod に戻す。

### PoEM Pod の交換・移設

- PoEM Pod を交換すると、PoEM Pod の ID (MAC アドレス) が変わるので、PoEM Server は新しい番号を振る。BMS の点の番号を保つには、PodMap.json で、新しい PoEM Pod に古い PoEM Pod の番号を割り当て直し、PoEM Server を再起動する。
- PoEM Pod を別の PoEM Server に移すと、移した先で番号が振られる。古い PoEM Server には、古いオブジェクトが残る。

### 子機の撤去

子機を撤去したら、PoEM Pod の SCAN ボタンを押して、ノードを消す。PoEM Server のオブジェクトは、PoEM Server を再起動するまで残る (5.7 節)。

### ファームウェアとソフトウェアの更新

| 対象 | 方法 | 注意 |
|---|---|---|
| 子機 | UPDI の書き込み器で書き込む | ユーザー領域の形が変わる更新では、アドレス・名前・係数が既定値に戻る (2.5.3 項)。更新の前に控えておく |
| PoEM Pod | UPDI の書き込み器で書き込む | 設定が保たれることを更新の後に確かめる |
| PoEM Link | UPDI の書き込み器で書き込む | — |
| PoEM Server | 実行ファイルを置き換える | setting.ini と PodMap.json は残す |

## 異常時の切り分け

| 現れ方 | 考えられる原因 | 確かめること |
|---|---|---|
| 子機のオブジェクトが現れない | PoEM Pod が PoEM Server に接続していない | PoEM Pod の赤の LED (2 回・3 回の点滅)、ブローカーの IP アドレスの設定 |
| 同上 | 子機が見つからない | 配線、I²C アドレスの重なり、PoEM Pod の SCAN ボタン |
| 同上 | config が届いていない | PoEM Pod の SCAN ボタンで config を送り直す |
| 状態が 12 (通信失敗) | 子機の配線が外れた、子機の故障 | 配線、子機を PoEM Link につないで確かめる |
| 状態が 12 が多くの子機で起きる | I²C のバスの不調 (配線が長い、子機が多い) | pod/diag の失敗の回数、延長ケーブルの長さ、プルアップ |
| 状態が 64 (準備中) のまま | 予熱の途中、センサの初期化の失敗 | 起動からの時間 (warmup_ms)、子機の再起動 |
| 状態が 1 (センサ応答なし) | センサの故障・外れ | 子機の交換 |
| 値が変わらない | PoEM Pod の停止、LAN の切断 | base + 0 (最後に受け取った日時) が進んでいるか |
| 値が別の子機のものに見える | 交換の後の config の喪失 | PoEM Pod の SCAN ボタン |
| BMS に PoEM Server が見えない | IP アドレス・ポート・Device 番号の重なり | setting.ini、ほかの PoEM Server の Device 番号 |
