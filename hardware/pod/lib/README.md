## HR873168AE (J301 に採用)

2026-11-18、HR871150C が LCSC・JLC とも在庫切れになったので替えた。ピンの役割 (P1〜P5、VC1±・VC2±) は HR871150C と同じで、中点タップの定格は 600 mA/タップ (HR871150C は 350 mA)、使用温度は −40〜85 °C。

- `HR873168AE.lbr`: 記号は PoEM Pod の回路図で使っている HR871150C の記号と同じ形・同じピン名 (P1〜P5、VC1±、VC2±、YEL1・YEL2、GRN1・GRN2、SHIELD)。Fusion で J301 を入れ替えても回路図の配線はそのまま残る。
  - LED の色の並びが HR871150C と逆 (HR873168AE は 11-12 が緑、13-14 が黄。11・13 がアノード)。記号のピン名の色と実物の色が合うように、YEL1・YEL2 を 13・14、GRN1・GRN2 を 11・12 につないだ。回路図のまま、緑がリンク (LINKLED)、黄が通信中 (ACTLED) になる。
  - フットプリントは [データシート](https://www.lcsc.com/datasheet/C19724783.pdf) (REV.00) の PCB Layout (部品面から見た図) と、JLCEDA/EasyEDA 公式ライブラリ (https://lceda.cn/、https://easyeda.com) の RJ45-TH_HR873168AE の穴の位置から作った。
  - 原点は位置決めの穴 (φ3.20、めっきなし) 2 つの中点。+y が差し込み口の向きで、口の前面は y = +10.90 (tDocu の破線)、後ろは y = −10.50、幅 16.10。
  - 信号ピン: 穴 0.9 mm (データシート φ0.89)、ピッチ 1.27 の千鳥。1・3・5・7・9 が y = −6.35、2・4・8・10 が y = −8.89。**1 番が −x 側** (HR871150C とは左右・前後の並びが逆)。6 番は無い。
  - LED: 穴 1.02 mm。11 (+6.725, +2.54)、12 (+6.725, +4.57)、13 (−6.725, +2.54)、14 (−6.725, +4.57)。
  - シールド: 穴 1.70 mm、(±7.875, −3.05)。記号のピン SHIELD に SH1・SH2 をまとめた。
- `HR873168AE.step`: 3D モデル (JLCEDA/EasyEDA 公式ライブラリ)。原点と向きはフットプリントに合わせていない。
- 高さは 13.55 mm。ケースに当たらないか確かめる。

## HR871150C (不採用)

- `HR871150C.lbr`: [データシート](https://www.lcsc.com/datasheet/C19724786.pdf) (REV.00) の Recommended PCB layout (部品面から見た図) から作った Fusion (Eagle 形式) のライブラリ。
  - 原点は位置決めの穴 (φ3.25、めっきなし) 2 つの中点。+y が差し込み口の向きで、口の前面は y = +10.80 (tDocu の破線)。基板の端に合わせて置く。
  - 信号ピン: 穴 0.9 mm、ピッチ 1.27 の千鳥。1・3・5・7・9 が y = −8.89、2・4・8・10 が y = −6.35。6 番は無い。1 番が +x 側 (□ のパッド)。
  - LED: 11-12 が黄 (+x 側)、13-14 が緑。穴 1.02 mm、y = +4.08。11・13 がアノード、12・14 がカソード (EasyEDA の記号の LED-VCC・GND と一致)。
  - シールド: 穴 1.63 mm、(±7.745, −3.05)。記号のピン SHIELD に 2 つのパッドをまとめた。
  - 記号のピン名は役割で付けた (下の対応表)。
  - EasyEDA の公式フットプリントと穴の位置を照らし合わせた (180° 回した向きで一致。信号ピンの x は EasyEDA の方が 0.1 mm ほどずれているので、データシートの 1.27 の格子にそろえた)。
- `HR871150C.step`: 3D モデル。原点と向きはフットプリントに合わせていない。Fusion のパッケージ エディターで 3D パッケージに割り当てるときに合わせる。EasyEDA の外で使うときの条件はこのライブラリの規約による。

### 従前の ARJM11C7-114-BA-EW2 とのピンの対応

HR871150C の役割は、データシートの内部の回路図 (トランスの巻き始めの点と、ケーブル側の J1〜J8 への配線) から読んだ。従前の品のピン名は PoEM Pod の回路図 (J301) による。

| 役割 | ARJM11C7 (従前) | HR871150C | 備考 |
|---|---|---|---|
| TD+ | 10 | P1 (1) | ケーブル側 J1 |
| TD− | 8 | P2 (2) | ケーブル側 J2 |
| TCT | 9 | P3 (3) | HR871150C は送受の中点タップが内部でつながっていて 1 本 |
| RCT | 4 | P3 (3) | 同上 |
| RD+ | 5 | P4 (4) | ケーブル側 J3 |
| RD− | 3 | P5 (5) | ケーブル側 J6 |
| VC1+ | 7 | P7 (7) | J1/J2 の中点 |
| VC1− | 2 | P8 (8) | J3/J6 の中点 |
| VC2+ | 6 | P9 (9) | J4/J5 |
| VC2− | 1 | P10 (10) | J7/J8 |
| 黄 LED アノード / カソード | (11〜14 のどれか、要確認) | 11 / 12 | |
| 緑 LED アノード / カソード | (11〜14 のどれか、要確認) | 13 / 14 | |
| シールド | 筐体のタブ | SH1・SH2 | HR871150C は内部で 1000 pF 2 kV を介してケーブル側の終端につながる |

- 対の中の +/− (TD+ と TD−、RD+ と RD−) は、トランスの点の向きから読んだ。10/100Base-T では、受信側の PHY がふつう極性を自動で直すので、取り違えても通信はできることが多い。送受の対 (TD と RD) の取り違えは致命的なので、こちらは確実に合わせる。
- 中点タップの VC1± と VC2± は、PoEM Pod ではそれぞれダイオードブリッジに入るので、+/− の向きはどちらでもよい。
- 従前の品は TCT と RCT が別のピンで、PoEM Pod では別々に C303・C304 (6.8 nF) につないでいる。HR871150C では 1 本になるので、C303・C304 をどうするか (1 つにまとめるか) を W5500 の参考回路で確かめる。
- HR871150C はケーブル側の Bob Smith 終端 (22 nF + 75 Ω × 4) を内蔵している。
- 従前の品の LED のピン (LED、LED_2〜LED_4) がどの色のアノード・カソードかは、回路図からは読み取れなかった。W5500 の LED 出力は Low で点灯するので、HR871150C ではアノード (11・13) を 3.3 V に、カソード (12・14) を R305・R306 (330 Ω) を通して W5500 につなぐ。
